# Politica di Sicurezza (Security Policy)

La sicurezza di questo progetto e la tutela dell'integrità del codice sono prioritarie.

---

## 🔒 Versioni Supportate

Solo l'ultima versione del codice presente sul branch `main` riceve attivamente aggiornamenti e patch di sicurezza.

| Branch | Supportato |
| :--- | :--- |
| `main` | ✅ Sì |
| Versioni / tag precedenti | ❌ No |

---

## 🚨 Segnalazione di una Vulnerabilità

Se hai individuato una vulnerabilità di sicurezza (es. potenziale leak di dati sensibili, vulnerabilità client-side XSS o falle nelle dipendenze):

1. **NON aprire una Issue pubblica su GitHub**: le issue pubbliche espongono la vulnerabilità prima che possa essere mitigata.
2. **Utilizza i GitHub Private Security Advisories**:
   - Vai nella scheda **Security** del repository su GitHub.
   - Clicca su **Advisories** e seleziona **New draft security advisory**.
   - Descrivi il problema indicando i dettagli tecnici, i file coinvolti e, se possibile, un proof-of-concept minimale o il fix suggerito.
3. In alternativa, puoi contattare direttamente il maintainer all'indirizzo associato al profilo GitHub.

---

## ⏱️ Tempi di Risposta

- **Conferma di ricezione:** entro 48 ore dalla segnalazione.
- **Valutazione e Piano di Rilascio:** entro 5 giorni lavorativi con il rilascio della patch su `main`.

Grazie per contribuire a mantenere sicuro questo progetto!
